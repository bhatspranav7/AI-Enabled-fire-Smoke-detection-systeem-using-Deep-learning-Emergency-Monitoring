    Configuration

    Thresholds and device settings live in configs/*.yaml and are loaded by the inference process at start-up (PDF §23). Edit the file and restart inference/run_live.py.

    • configs/thresholds.yaml — warning / confirmed / clear thresholds, temporal window, sensor fusion, zone
    • configs/device_config.yaml — camera source, device id/name/location, backend URL
    • configs/model_config.yaml — checkpoint, image size, NMS
    • configs/notification_config.yaml + .env — channels and secrets

    State machine

    NORMAL → WARNING (possible target, short evidence) → CONFIRMED (persistent high-confidence detection, optional sensor confirmation) → RECOVERY (stable safe readings) → NORMAL. SENSOR_WARNING = persistent sensor evidence with no visual target.

    Safety: this is an academic prototype. Physical automation only drives isolated low-voltage loads and never certified fire-safety equipment.
